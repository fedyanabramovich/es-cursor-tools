# es-cursor-tools

Магазин плагинов Cursor для команды. Сейчас в нём один плагин: `isivr`.

## Установка магазина

1. Откройте Customize в боковой панели Cursor.
2. Нажмите **+ Add Marketplace**.
3. В поле **Repository** вставьте `github.com/fedyanabramovich/es-cursor-tools` без `https://`.
4. В **Scope** оставьте **User** и нажмите **Import**.
5. Откройте вкладку **Personal**. Появится блок **Fedyanabramovich Es Cursor Tools**.

## Плагин isivr

Плагин даёт агенту доступ к ISIVR через API: агент собирает приложения в дизайнере и администрирует платформу. Внутри два компонента:

- MCP-сервер `isivr` — вызывает API ISIVR от имени вашей учётной записи Keycloak;
- навык `isivr-applications` — правила сборки схем: блоки, переходы, звуки, проверка.

Нужен Node.js 18 или новее.

### Что умеет

Сборка приложений:

- создать приложение по текстовому описанию сценария или по странице Confluence;
- изменить существующее приложение: добавить меню, ветку, проверку, перевод на очередь;
- загрузить звуки из файлов и подставить их в блоки;
- проверить схему и показать ошибки валидации;
- клонировать приложение или версию.

Администрирование:

- пользователи и роли;
- серверы, группы серверов и кластеры, привязка номеров;
- календари и праздничные периоды;
- звуки и группы звуков;
- динамические параметры и динамические списки, включая чёрные и белые списки номеров;
- функции интеграций;
- таблицы маршрутизации и маршруты;
- группы приложений;
- задачи публикации: создание, проверка конфликтов, откат.

Агент не публикует и не делает версию стабильной без прямой просьбы.

### Установка

1. В блоке **Fedyanabramovich Es Cursor Tools** у плагина `isivr` нажмите **Add**.
2. Откройте плагин и нажмите **Configure**.
3. Заполните пять полей и сохраните.

### Настройки

| Поле | Что указать |
| --- | --- |
| Адрес ISIVR | Базовый URL веб-интерфейса стенда без завершающего слэша |
| Адрес Keycloak | Полный URL получения токена |
| Клиент Keycloak | Идентификатор клиента в Keycloak |
| Логин Keycloak | Ваша учётная запись на стенде |
| Пароль Keycloak | Пароль этой учётной записи |

Пример заполнения. Эти адреса и клиент подставлены по умолчанию, их нужно заменить на свои:

```text
Адрес ISIVR:     https://isivr.example.net
Адрес Keycloak:  https://keycloak.example.net/realms/example/protocol/openid-connect/token
Клиент Keycloak: client
Логин Keycloak:  ivanov1
Пароль Keycloak: ваш пароль
```

Адрес Keycloak всегда заканчивается на `/protocol/openid-connect/token`. Логин и пароль хранятся только в настройках Cursor, в репозиторий они не попадают.

### Если не работает

- Агент не видит инструменты ISIVR — проверьте, что плагин включён, и перезапустите Cursor.
- Ошибка «Keycloak отклонил вход» — проверьте адрес Keycloak, клиент, логин и пароль в **Configure**.
- Ошибка «Не задано …» — заполнено не всё в **Configure**.
